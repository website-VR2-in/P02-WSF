FAQ

Qu'est-ce qu'un « run » ?

Un run est une requête à votre agent qui renvoie une réponse. Le streaming, les reprises et les appels internes au modèle ne multiplient pas votre compteur — vous payez ce que vos utilisateurs reçoivent.

Qui héberge le modèle ?

Vous apportez le modèle (n'importe quel endpoint compatible OpenAI, ou le vôtre). DeployMyClaw héberge le runtime de l'agent — ce qui reçoit les requêtes, appelle votre modèle et répond. Les dépenses modèle restent sur la facture de votre fournisseur, sauf si vous le connectez via nous.

Où sont mes données ?

Dans des data centers UE, isolées par tenant. Les journaux de requêtes/réponses suivent votre paramètre de rétention (7/90 jours ou désactivé). Nous n'utilisons jamais vos charges utiles pour entraîner des modèles partagés.

Puis-je partir plus tard ?

Oui. Votre code et votre configuration d'agent s'exportent à tout moment, et les endpoints suivent la forme compatible OpenAI, donc changer d'hôte est un changement d'URL de base.
