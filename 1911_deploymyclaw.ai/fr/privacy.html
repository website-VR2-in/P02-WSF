Politique de confidentialité

Dernière mise à jour : 9 novembre 2026

Responsable de traitement. DeployMyClaw — contact : hello@deploymyclaw.ai.

Ce site web. Site statique : aucune donnée de visiteur n'est stockée sur nos serveurs. Le formulaire de contact s'ouvre dans votre client de messagerie (mailto).

Cookies & analytics. Google Analytics (Google LLC) avec anonymisation de l'IP ne fonctionne que si vous y consentez via la bannière. Le consentement est stocké dans votre navigateur (localStorage) et peut être retiré en effaçant les données du site.

La plateforme. Le code et la configuration des agents sont stockés par tenant dans des data centers UE, isolés des autres tenants. Les journaux de requêtes/réponses suivent votre paramètre de rétention (7 jours, 90 jours ou désactivé). Les identifiants modèle sont stockés dans votre coffre, jamais dans le nôtre. Nous n'utilisons jamais vos charges utiles ou votre code d'agent pour entraîner des modèles partagés.

Rétention. Emails de contact du site : tant que nécessaire à la relation commerciale. Journaux plateforme : selon votre paramètre de rétention. Enregistrements de facturation : comme exigé par la loi.

Vos droits (RGPD). Accès, rectification, effacement, limitation, opposition, portabilité. Écrivez à hello@deploymyclaw.ai ; nous répondons sous un mois. Le code et la configuration de l'agent s'exportent à tout moment.
